# 影视人物妆造方案

### Film Character Styling

**从剧本中的人物，走到片场里的每一套衣服。**

面向短片、电影与剧集筹备的 AI Skill。根据剧本、人物小传、美术资料和演员信息，整理服装、发型与妆容设计，把故事日、出镜场次、服装套数和采购需求放进同一份清单，再据此制作可编辑的妆造汇报 PPT 与逐套贴图 Excel。

## 它能帮你完成什么

| 筹备任务 | 处理方式 |
| --- | --- |
| 人物妆造设计 | 将性格、人物处境、演员面貌与美术空间转化为服装、发型和妆面安排 |
| 剧本拆分 | 区分故事日、回忆阶段、连续场景、实际出镜与声音出演 |
| 接戏与换装 | 为每套造型建立固定编号，明确对应场次与状态变化 |
| 套数统计 | 分别统计角色造型、演员需求、复用单件和同款备份 |
| 采购与处理 | 标明自有、已有、借用、另购，以及做旧、污染和湿戏要求 |
| 汇报与试装 | 用 PPT 展示设计，用 Excel 记录尺码、采购与逐套试装照片 |

适合妆造、服装、美术及独立影像创作者，用于前期方案、试装准备和剧本修改后的方案更新。

## 设计重点

### 让方案和清单对得上

PPT 与 Excel 使用同一份角色、故事日、造型与场次数据。调整某个角色的套数或演员关系时，检查两份产物中的编号与场次是否一致。

### 把造型数和备衣量分清楚

同一件衬衫加上制服外套，可以形成另一种造型；污染戏准备的两件同款衬衫，则属于同一造型的实物备份。分别记录这些情况，便于采购和现场准备。

### 每套造型都有自己的照片位

Excel 为每套造型独立保留上装、下装、全身穿搭三个图片区域。即使裤鞋复用，也保留该套的完整试装记录。

### 把缺项留给真实资料

演员照片或尺寸未齐时，可先完成文字方案和场次安排。未知尺码留空；故事日、服装变化与污染状态依据本次材料判断。

## 工作流程

1. **读取材料** — 核对剧本版本、人物设定、美术方向与最新修改。
2. **拆分场次** — 整理人物与演员映射、故事日、出镜场次和换装依据。
3. **建立造型清单** — 固定造型编号，安排服装、妆发、复用与备份。
4. **制作方案** — 根据需要加入参考图、概念图或真实试装照，并注明来源与类型。
5. **输出与核对** — 制作 PPT 和 Excel，检查套数、场次、采购口径及版面。

## 快速开始

### 准备运行环境

本仓库提供 Skill 指令与参考规范。使用前，将完整的 `film-character-styling` 目录安装到所用 AI 助手支持的 skills 目录，保留 `SKILL.md`、`agents/` 和 `references/` 的相对位置。具体安装入口以宿主工具为准。

制作完整交付文件时，运行环境需要具备 **Presentations** 与 **Spreadsheets** 技能及相应文件生成能力。需要 AI 概念图时，再使用 **imagegen** 技能与工具。仓库本身不包含独立运行的 PPT 或 Excel 生成程序。

### 提供项目材料

| 材料 | 用途 |
| --- | --- |
| 最新完整剧本 | 拆分人物、故事日、出镜场次及服装变化 |
| 人物小传与导演说明 | 理解人物状态、关系与设计方向 |
| 美术资料与拍摄条件 | 判断年代、季节、温度、空间色彩和材质 |
| 演员照片与尺码 | 调整妆发设计，准备实际服装 |
| 已有服装与采购约定 | 区分可用实物、待采购项目和备份需求 |
| 现有方案与修改意见 | 延续已确定内容，更新对应造型和场次 |

先提供剧本即可启动拆分。其余材料可逐步补充。

### 示例请求

```text
使用 $film-character-styling，根据附件中的剧本、人物小传和美术资料，
制作本片的人物妆造方案。

先整理人物与演员对应、故事日、出镜场次和服装套数，
再输出可编辑的妆造汇报 PPT 与逐套贴图 Excel。

先完成文字方案，暂不生成图片。
演员尺寸缺项留空；已有服装和需要采购的服装分别列出。
```

已有方案需要更新时，可以这样提出要求。

```text
使用 $film-character-styling，以附件中的最新方案为基础，
按新版剧本更新主角的故事日和换装安排。
同步检查 PPT 与 Excel 中的造型编号、场次和采购清单，
保留已经确认的设计与演员资料。
```

## 交付内容

| 产物 | 主要内容 |
| --- | --- |
| **妆造汇报 `.pptx`** | 人物设计依据、服装与妆发、造型差异、场次对应、图像参考及采购重点 |
| **工作清单 `.xlsx`** | 逐套贴图、套数总览，以及按需设置的服装明细与演员尺码表 |

两份文件使用一致的造型编号和版本标识。图片暂缺时，仍可完成文字、场次和采购安排，并保留照片空位。指定在线制作平台时，交付形式取决于该平台支持的编辑与导出能力。

## 项目资料管理

每个项目的数据与产物保存在该项目的工作目录。可复用 Skill 只保留通用工作方法，演员照片、身体尺寸及未公开剧本应按项目授权范围管理。
